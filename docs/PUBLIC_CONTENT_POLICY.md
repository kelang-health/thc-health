# THC Health — Public Content Policy

## หลักการ

หน้าเว็บไซต์สาธารณะควรเผยแพร่เฉพาะข้อมูลที่ประชาชนจำเป็นต้องใช้เพื่อรู้จักหน่วยบริการ เข้าถึงบริการ และเข้าใจบริบทสุขภาพของพื้นที่ในระดับภาพรวม

## เผยแพร่ได้

- ชื่อหน่วยบริการ หน่วยงานสังกัด ที่ตั้ง และพื้นที่รับผิดชอบ
- ประวัติหน่วยบริการในระดับองค์กร
- วิสัยทัศน์ พันธกิจ เป้าประสงค์ และวัฒนธรรมองค์กร
- เวลาทำการและตารางบริการ
- จำนวนหมู่บ้าน ชุมชน และเครือข่าย อสม. ในระดับภาพรวม
- จำนวนประชากรในระดับพื้นที่รวม พร้อมระบุปีและแหล่งข้อมูล
- สถิติบริการรวมของหน่วยงาน
- สัดส่วนหรือแนวโน้มสุขภาพที่เป็นข้อมูลรวมและมีประโยชน์ต่อการสื่อสารสาธารณะ
- ประเด็นสุขภาพสำคัญในระดับภาพรวม เช่น สังคมสูงอายุ NCDs การป้องกันโรค

## ไม่เผยแพร่บนเว็บไซต์สาธารณะ

- CID, PID, HN หรือ identifier ใดที่เชื่อมกลับไปยังบุคคล
- เวชระเบียน การวินิจฉัย ยา ผลตรวจ หรือประวัติการรักษารายบุคคล
- LINE user ID หรือ patient mapping
- รายชื่อบุคลากรรายบุคคล วุฒิการศึกษา หรือข้อมูลส่วนบุคคลที่ไม่จำเป็นต่อการรับบริการ
- รายชื่อ อสม. รายบุคคล
- จำนวนผู้ป่วยหรือผู้เสียชีวิตในกลุ่มย่อยที่มีจำนวนน้อยและอาจเพิ่มความเสี่ยงต่อการระบุตัวบุคคลหรือการตีตราชุมชน
- รายละเอียดผู้สูงอายุติดบ้าน/ติดเตียง ผู้พิการ LTC หรือกลุ่มเปราะบางในระดับที่ทำให้คาดเดาบุคคลได้
- ตารางสาเหตุการเสียชีวิตหรือข้อมูลสุขภาพจิต/การฆ่าตัวตายในรายละเอียดระดับพื้นที่ย่อย
- ข้อมูลสิทธิการรักษารายบุคคลหรือรายชื่อผู้มีสิทธิ

## หลักการนำเสนอข้อมูลสุขภาพ

1. ใช้ aggregate data เท่านั้น
2. ระบุปีและแหล่งข้อมูลทุกครั้ง
3. ถ้าข้อมูลมีหลาย denominator ให้เขียนให้ชัดว่าเป็นทะเบียนราษฎรหรือประชากรสำรวจ
4. หลีกเลี่ยงการตีตราพื้นที่หรือกลุ่มประชากร
5. ข้อมูลที่เปลี่ยนเร็วควรมีวันที่อัปเดต
6. ถ้าจำนวนกลุ่มย่อยน้อย ควรแสดงเป็นแนวโน้มหรือข้อความสรุปแทนตัวเลข
